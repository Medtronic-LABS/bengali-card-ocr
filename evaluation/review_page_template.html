কার্ড লেবেলিং · Card labeling

নির্দেশনা · Instructions (about 1 hour; progress saves automatically in this browser)
  1. লাল বাক্সের ভিতরে যা লেখা আছে ঠিক তাই লিখুন। Type exactly what is written inside the red box.
  2. বাংলা সংখ্যা বাংলায়, ইংরেজি সংখ্যা ইংরেজিতে লিখুন। Keep the numeral script as written (০১২ vs 012). Use the keypad if you have no Bengali keyboard.
  3. দুই লাইনের তারিখ: উপরের লাইন, তারপর ↵, তারপর নিচের লাইন (যেমন ১.৩ ↵ ২৬)। Two-line dates: top line, new line (↵), bottom line, e.g. ১.৩ ↵ ২৬. Keep dots and slashes as written.
  4. টিক বা ক্রস হলে ✓ বা ✗ চাপুন। Ticks/crosses: use ✓ or ✗.
  5. ফাঁকা হলে "খালি" চাপুন। পড়া না গেলে "পড়া যায় না" চাপুন — অনুমান করবেন না। Empty box: press Blank. If you cannot read it, press Can't read. Never guess.
  6. শেষ হলে (বা মাঝপথে) "ডাউনলোড" চাপুন এবং ফাইলটি লক্ষ্যকে পাঠান। When done (or to stop for now), press Download and send the file to Lakshya.

Shortcut: Ctrl/⌘ + Enter saves the box you are typing in and moves to the next one. Nothing on this page is sent over the internet. It shows patient handwriting: keep the file private.
